# Data files

This compact release contains only the files used by the Scene15 experiment:

- `Scene_15.mat`: Scene15 multi-view features and labels. LASI-IMVC uses the first two views.
- `clip_cache/scene15_vitb32/clip_img_feat.pt`: aligned ViT-B/32 CLIP image features.

The code license does not replace or supersede the original dataset terms. Before mirroring or
redistributing these files, verify the Scene15 license and attribution requirements applicable
to your use.
